## The brief

1. **What is the app, and who is it for?** Scribbl — a one-month digital farewell ritual for the Bennett B.Tech CSE Class of 2026. Batchmates sign each other's virtual shirts with handwritten marks, doodles and stickers; after the window the shirts seal into a public yearbook.
2. **The core action:** open a friend's shirt, put a mark on it. Second core action: watch marks land on *your* shirt.
3. **How it should feel:** like the last night of college — warm, a little ceremonial, yours. (Founder's words across docs: "we're drawing on the person", "scribble day happens outdoors", "a memory ritual, not a social network".)
4. **What exists already:** name (Scribbl), a live theme ("Sunlit Lawn": cream paper, ink browns, violet `#6f54df`, Caveat/Patrick Hand/Permanent Marker, whiteboard + sticker-note components), full codebase, docs. Logo: a hand-drawn scribble star. Photography: none licensed; illustration: placeholder campus SVGs.
5. **What they need:** validate the current theme; generate alternative theme concepts for the app UI (this document + `explore.html` renderings).
6. **Image generation:** not used. All imagery is hand-drawn SVG (honest substitutes), noted per direction.

## Category defaults being refused

- **Yearbook/memory-app default:** pastel scrapbook, polaroid stacks, washi tape, kraft paper, handwriting-as-chrome. (Sunlit Lawn already sits halfway in this; the incumbent counts as a history row.)
- **Social-app default:** feed-first, avatar rows, engagement pills, heart reactions as the primary verb.
- **Colour clichés of the category:** cream + terracotta "nostalgia" palette; violet AI gradient; marigold-and-cream "Indian wedding" wash.
- **Structural default:** dashboard skeleton (hero stat, 2×2 tiles, recent activity) — the core action owns the first screen.

## The three concepts

### A — "The Last Night" (object / dark)
> **Scribbl is the jersey on the hostel floor at midnight — the marker going around the circle one last time.**

- Ground: warm near-black `#161310` (hostel lamplight, lights out); raised `#211C17`; ink `#F4EDE1`; ink-2 `#AFA18C`; rule `#373028`.
- Accent: **marker red `#E8453C`** — one role only: the live signing action (the pen that's moving now / the Sign button). On-accent `#FFF6F2`.
- Type: **Archivo** — display at weight 800, width 125% (Expanded), −2% tracking; UI at 400/600. User signatures stay **Caveat** (user content, not chrome). Five sizes: 40 display / 22 title / 17 body / 14 secondary / 11 caption.
- Richness: the shirt as a **lit object** — fabric shading, seam stitching, collar highlight; marker pens and doodles scattered around it like objects on a floor.
- Signature interaction: **the ink soaks** — a published mark lands as a wet stroke that dries (saturates → settles) over 600ms, with a haptic tick when it's set. Reduced motion: mark appears settled.
- Its own slop to refuse: gamer-HUD neon, glow shadows, lime-on-black fintech.

### B — "The Annual" (printed / light)
> **Scribbl is the last page of the school annual — the one everyone signs, the one that gets kept.**

- Ground: newsprint `#ECEAE4` (not cream); raised page `#F8F7F3`; ink `#211E19`; ink-2 `#6F695E`; rule hairline `#D9D6CD`.
- Accent: **seal blue `#2A4B8D`** — one role: the stamp of record (verified mark, primary action, the seal). On-accent `#F8F7F3`.
- Type: **Newsreader** — masthead serif; display 600 with one italic word for meaning; UI 400/600. Signatures stay Caveat. Folio line on every screen: "Class of 2026 · CSE".
- Richness: **photography** as art direction (the convocation film strip; in mockups, drawn duotone plates stand in — honest substitute, one hand, one duotone). Captions under every image, hairline rules, numbered marks.
- Signature interaction: **the press** — publishing a mark stamps it into the page like letterpress (ink bites into paper: 1px settle + imperceptible rotation), then the mark is numbered ("No. 24").
- Its own slop to refuse: cream-and-terracotta wellness, scrapbook washi, sepia filters.

### C — "House Colours" (play / colour-field)
> **Scribbl is the farewell assembly — the batch colour behind you, one white shirt in the spotlight.**

- Ground: **the owner's shirt fabric as a saturated field** — marigold `#E29A2E` for Ishita; the system is a named set (marigold / cobalt / oxblood / forest / ink) chosen per shirt colour. Ink `#191410`; on-field secondary `rgba(25,20,16,.62)`; the white shirt object `#FAF7F0`.
- Accent: **none** — neutral ink carries chrome; the field *is* the colour system (colour-field rule: grounds are a system, not accents).
- Type: **Big Shoulders Display** — condensed poster face, 800, huge (56–72), tight; UI 400/600 in the same; signatures Caveat.
- Richness: **colour-material** — the woven field (2% weave texture, physical, one-directional) + the white shirt as the single object catching light.
- Signature interaction: **the shirt fills** — each new mark slightly deepens the field's saturation for everyone in the room; the batch watches the colour ripen toward seal day (colour as information: fullness you can feel).
- Its own slop to refuse: rainbow confetti, Memphis kindergarten, grounds that change for no reason (the ground = this owner's shirt colour, always).

## WINNER (after critique rounds 1–2): C — "House Colours"

Critic verdict round 1: Done; pick = C. Round 2 confirmed the five asks landed (see CRITIQUE.md).

### Token table (light = the field; dark = the field deepened, never grey)

The field is a **system, one per shirt colour** (colour-field rule: grounds are a system, not accents):

| Shirt colour | Field (light) | Field (dark) | Ink | On-field secondary |
|---|---|---|---|---|
| Natural / undyed (default) | `#E29A2E` marigold | `#7A4E12` deep marigold | `#191410` | `#4A3A20` |
| Cobalt jersey | `#2E4FA3` | `#16294F` | `#F4F1E8` | `#B9C4DE` |
| Oxblood | `#8C3327` | `#43180F` | `#F4EDE1` | `#D6B3A9` |
| Forest | `#3E6B47` | `#1D3421` | `#F1EFE6` | `#B9C9BC` |
| Ink (black shirt) | `#22201C` | `#111010` | `#F4EDE1` | `#B7AA94` |

Chrome roles (constant across fields): `ink` per table; `raised` = the white shirt `#FAF7F0` (the only raised object); `rule` = ink at 28%; **accent = none** — the field is the colour system and ink does every chrome job. Semantic states, if needed, use ink weight/underline, not hue.

### Type (5–7 steps, one voice)

- Display: **Big Shoulders Display** 800, caps, 56–64 (hero name), 27–28 (screen titles), tracking −0.5%.
- UI: **Big Shoulders Display** 400/700 at 15–16 (body), 12.5 (meta caps +10–14% tracking), 11 (nav labels caps).
- User content: **Caveat** 16–30 (signatures, on-field notes) — content, never chrome.
- Counts and zone stats: tabular numerals.

### Signature interaction (storyboard)

**The shirt fills.** Each published mark deepens the owner's field saturation by one step (max 10 steps toward seal day). Frames: mark published → ink soaks into the shirt SVG (600ms, spring) → the field hue shifts +2% saturation for everyone in the room (cross-fade 300ms) → the batch progress line ("23 of ~40 marks this week") ticks. Haptic: single tick on publish. Reduced motion: mark appears settled; field updates on next render.

### What carries over from the other directions (per critic)

- From B: the **№ stamp** — published marks are numbered in order ("№ 25 · Kabir · 2h ago"); the numbering is the archive's memory hook.
- From A: the **live pill** ("3 here now" with the single red-tick dot) — presence deserves one colour job; borrow it as the only non-ink colour, reserved for "signing is happening now".
- From the incumbent: the **whiteboard** stays the announcement component (batch-level notices), rendered on-field with an ink frame instead of aluminium.

### Implementation notes (web, Sunlit-Lawn replacement path)

1. Tokens live in `tailwind.config.ts` as `field-*` scales + `ink`/`on-field`; page ground = `field-{owner}` via a `data-field` attribute so components stay field-agnostic.
2. Fonts: swap Inter body → Big Shoulders Display (400/700) + keep Caveat for signatures; drop Patrick Hand and Permanent Marker (whiteboard marker text can go Big Shoulders caps or Caveat, pick one).
3. The 8-swatch ink tray stays exactly as shipped (`CANVAS_COLORS`) — it is the domain palette.
4. Dark mode = `field-*-deep` per table; never grey.

## UPDATE (rounds 3–4): House Colours is now a full system — final critic score 12×5 + Fidelity 5

Founder picked C ("the marigold is probably the better style") and asked for more — or something even better. The direction was expanded to 8 frames (`explore-c.html`, best renders in `shots/r4/`): shirt screens in three fields (marigold / cobalt / night), home, batch wall, landing, signing studio, signature storyboard. What the expansion settled:

- **The dye wash stays** (critic-confirmed): one diagonal light band from top-left (~6–16% falling to 0), identical on marigold/cobalt/landing/home, **absent on night** — sun on dipped fabric, agreeing with the hard offset shadows' one light direction. Not a decoration; it is the system's only gradient and it is physical.
- **Colour as words at list level:** classmate rows carry "FIELD · COBALT" as tracked caps text, never coloured chips — the field is chromatic only at the object level (the person's own page), so lists never turn confetti.
- **Night mode** = the same field deepened (marigold → deep marigold `#7A4E12`), ink inverted — never grey.
- **Signature moment, fully specified:** mark lands wet → ink soaks 600ms → field deepens one step → "№ 25" stamps; per-owner 10-step ripeness ("ISHITA'S FIELD · STEP 7 OF 10"); haptic tick; reduced-motion fallback.
- **Landing** adopts the system (poster headline, real countdown whiteboard "312 SHIRTS CLAIMED · signing closes 31 Oct"), replacing the off-token amber front door flagged in the audit.
- **Steals absorbed:** № stamping from B (in plain tracked caps, not the blue box), live-presence red tick from A (the only non-ink colour, meaning "signing is happening now").
- Implementation path: `field-*` token scales in tailwind keyed by `data-field` on the page root; Big Shoulders Display replaces Inter as body; Caveat stays signatures-only; whiteboard component survives with ink frame + ink caps text.

Final files: `explore-c.html` (source) · `shots/r4/` (rendered frames, `sheet.png` first) · scores in `CRITIQUE.md`.
